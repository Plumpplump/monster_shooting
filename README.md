# Monster Shooting Challenge

A small stationary shooting gallery for the desktop, written in Python with
[Ursina](https://www.ursinaengine.org/). You stand still, aim with the mouse
and shoot monsters as they enter, warn up and attack. Three levels, four
monster types, interruptible attacks, and one- or two-player play on a single
mouse.

## The game

- **Three levels, four waves each.** Wave 4 of every level is a boss wave.
- **Four monster types** - a weak blob, a medium type, a hard type and a
  boss. Each has its own health, points, attack damage and timing.
- **Interruptible attacks.** A monster enters, waits, shows a red-ringed
  warning and then attacks. Shoot it during the warning and the attack is
  cancelled (the shot still counts).
- **Health and score.** You start with 100 HP; attacks cost 10-30 HP. Health
  carries between waves and is restored to 100 after levels 1 and 2. Points
  are scored only for defeating monsters (10-100 points each at level 1;
  health and points triple per level).
- **Two-player mode** alternates full runs on the same mouse. The match is
  ranked by: finished the game > score > remaining health > shorter play time
  (pause and handover time excluded); a full tie is a draw.

## Requirements

- Python 3.13 or newer (developed and tested with Python 3.13.16).
- [Ursina](https://pypi.org/project/ursina/) 8.3.0 (which brings Panda3D
  1.10.16).
- No other assets to download - the shapes are generated by Ursina and the
  sounds under `assets/sounds/` are pre-generated (see
  `tools/generate_sounds.py` if you want to regenerate them).

On macOS, `compat.py` configures an OpenGL core-profile context and patches a
few Ursina/Panda3D quirks on that driver (transparency blending, UI scale,
text rendering). It is applied automatically by `main.py` and is harmless on
other platforms.

## Installation

```sh
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install "ursina==8.3.0"
```

## Running

```sh
python main.py
```

## How to play

- **Move the mouse** to aim the crosshair.
- **Hold the left mouse button** to fire. The first shot fires immediately and
  then one shot every 0.15 s; extra clicking does not shoot faster. Each shot
  deals 1 damage and hits the closest monster under the crosshair.
- **A monster flashing with a red ring is about to attack** - shoot it during
  the warning to interrupt the attack.
- **Esc** opens the pause menu (pause freezes everything, including monster
  attack timers). Click the menu buttons with the mouse.
- Clear every monster in a wave to advance; clear four waves to finish a
  level. Beat level 3 to win the run.
- In two-player mode, hand over the mouse at the "PLAYER 2" start screen.

The main menu also offers a **HOW TO PLAY** screen with a short summary of
these rules.

## Project layout

| File | Purpose |
| --- | --- |
| `main.py` | Entry point; creates the app and wires the update loop. |
| `game.py` | Game controller: state machine, rounds, shooting, scoring. |
| `config.py` | All tunable data: enemy stats, waves, timings, UI colors. |
| `enemy.py` | Monster entities (movement, attack cycle, visuals). |
| `waves.py` | Wave/level definitions and the spawn manager. |
| `attack_coordinator.py` | Makes sure only one monster warns at a time. |
| `player.py` | Player state (health, score, stats). |
| `ui.py` | Menus, HUD, crosshair, announcements. |
| `effects.py` | Popups, flashes and other feedback effects. |
| `sound.py` | Sound playback helper. |
| `compat.py` | macOS/OpenGL compatibility shims (applied automatically). |
| `selftest.py` | Headless logic checks (`python selftest.py`). |
| `tools/generate_sounds.py` | Regenerates `assets/sounds/*.wav`. |

## Development notes

`selftest.py` runs a headless suite of logic checks (no window needed):

```sh
python selftest.py
```

`main.py` understands a few environment variables used by automated smoke
tests - `MS_AUTOPLAY=1` (demo run), `MS_QUIT_AFTER=<seconds>`,
`MS_SCREENSHOT_AT=1,20,...` and `MS_SCREENSHOT_DIR=<dir>`. They are not needed
for normal play.
